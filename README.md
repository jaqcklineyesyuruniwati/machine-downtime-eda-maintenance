# machine-downtime-eda-maintenance
Analisis data waktu henti tak terjadwal (downtime) pada mesin produksi pengolahan logam (machine_downtime.csv), mencakup pembersihan data (data cleaning koreksi usia mesin negatif &amp; imputasi median biaya perbaikan), serta identifikasi mesin kritis menggunakan visualisasi boxplot dan countplot.
